# 官網上線與永久免費網址

本網站是純靜態 HTML/CSS/JS，適合放在 GitHub Pages、Cloudflare Pages、Netlify 或任何靜態主機。

## 目前交付狀態

- 完整網站資料夾：`vegetarian-zongzi-site`
- 首頁：`index.html`
- 樣式：`styles.css`
- 互動：`script.js`
- 圖片資產：`assets/zongzi-hero.jpg`、`assets/product-*.jpg`

## 能用的網址分兩種

### 1. 目前立刻能用的本機網址

此網址在這台電腦可直接打開：

```text
file:///C:/Users/user/Desktop/claude-broll/vegetarian-zongzi-site/index.html
```

### 2. 公開且永久免費的網址

公開網址需要部署到免費靜態主機。最穩定的免費方案是 GitHub Pages，但必須有你的 GitHub 帳號或 repo 授權。

建議網址格式：

```text
https://你的GitHub帳號.github.io/vegetarian-zongzi-site/
```

如果你使用自訂 GitHub repo 名稱，例如 `su-zong-shop`，網址會是：

```text
https://你的GitHub帳號.github.io/su-zong-shop/
```

## 為什麼不能直接憑空產生公開網址

這台環境目前沒有 GitHub CLI，也沒有可用的 GitHub 登入狀態或遠端 repo。沒有你的 GitHub、Cloudflare 或 Netlify 帳號授權時，任何看起來像公開網址的字串都不會真的上線。

因此我不再把 `https://你的帳號.github.io/...` 當作已交付網址；它只是部署完成後的格式。真正公開網址必須等你用自己的免費帳號部署後才會生效。

## 最快上線步驟：GitHub Pages

1. 建立 GitHub repo，例如 `vegetarian-zongzi-site`。
2. 上傳此資料夾內的所有檔案。
3. 到 repo 的 `Settings`。
4. 點 `Pages`。
5. Source 選 `Deploy from a branch`。
6. Branch 選 `main`，資料夾選 `/root`。
7. 儲存後等待 1 至 3 分鐘。

上線後會得到：

```text
https://你的GitHub帳號.github.io/vegetarian-zongzi-site/
```

## 其他免費方案

| 平台 | 免費網址格式 | 適合情境 |
|---|---|---|
| GitHub Pages | `https://帳號.github.io/repo/` | 永久免費、版本控管、適合靜態官網 |
| Cloudflare Pages | `https://專案名.pages.dev/` | 速度快，可接自訂網域 |
| Netlify | `https://專案名.netlify.app/` | 拖拉上線最簡單 |
