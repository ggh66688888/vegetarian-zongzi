# 素肉粽專賣店官網

這是一個可直接上線的素肉粽專賣店靜態官網。

## 聯絡資訊

- 銷售經理：柯紫姍、謝騰騏
- 地址：新北市樹林區中興街 42 號
- 電話：02-26820850
- 傳真：02-26820843

## 檔案

- `index.html`：官網首頁
- `styles.css`：版面與視覺樣式
- `script.js`：訂購估價與摘要互動
- `assets/zongzi-hero.jpg`：主視覺圖片，來源為 Unsplash
- `assets/product-*-photo.png`：四張商品卡圖片，裁切自使用者提供的 `2.png`
- `docs/競爭對手分析_素肉粽.md`：競品分析與對比表
- `docs/上線與永久免費網址.md`：免費部署方案
- `docs/素材授權.md`：圖片來源、授權與替換說明

## 本機預覽

直接用瀏覽器開啟：

```text
vegetarian-zongzi-site/index.html
```

或在此資料夾啟動任一靜態伺服器。

## 建議免費網址

GitHub Pages：

```text
https://你的GitHub帳號.github.io/vegetarian-zongzi-site/
```

目前此環境未登入 GitHub/Cloudflare/Netlify，因此無法直接替你建立公開網址。網站已經是可部署版本。
